Documentación de Klvro

Guía para instalar, configurar y administrar Klvro desde Discord y desde el panel web.

Primeros pasosAñade el bot y entra al panel. TicketsConfigura soporte y paneles. Anti-RaidProtege el servidor de acciones masivas.

Primeros pasos

Entra a Klvro con tu cuenta de Discord, elige un servidor donde tengas permisos de administración y añade el bot. Una vez Klvro esté dentro del servidor, pulsa Configurar.

Importante: el rol de Klvro debe estar por encima de los roles que quieras que gestione.

Panel web

Desde el dashboard puedes activar módulos, elegir canales, roles y guardar la configuración de cada servidor. Los cambios quedan vinculados al servidor seleccionado.

Tickets

Activa el módulo, selecciona la categoría donde se crearán los tickets, el rol del staff y el canal donde Klvro publicará el panel.

  • El panel se publica automáticamente en el canal elegido.
  • Si vuelves a editarlo, Klvro actualiza el mismo mensaje.
  • El preview del panel se muestra desde la web.
  • Premium desbloquea más opciones visuales.

Moderación

Incluye controles automáticos como antispam, bloqueo de enlaces y registro de acciones de moderación.

Anti-Raid

Protege entradas masivas, creación o borrado repetido de canales y roles, webhooks sospechosos, bans, kicks y permisos peligrosos.

Recomendación: prueba primero el modo normal antes de usar configuraciones estrictas.

Administración

Klvro incluye herramientas para banear, expulsar, aplicar timeout, warns, limpiar mensajes, gestionar roles, bloquear canales y más.

Autoroles

Permite asignar automáticamente un rol cuando un usuario entra al servidor.

Registros

Centraliza eventos del servidor como mensajes eliminados, entradas y salidas de miembros y cambios de canal de voz.

Comandos

/pingMuestra la latencia del bot.
/panelMuestra el enlace al dashboard.
/ticketpanelPublica el panel de tickets.
/closeCierra el ticket actual.
/antiraidConsulta o controla el Anti-Raid.

Premium

Klvro tiene funciones adicionales según el plan activo. Premium Lite amplía opciones de configuración y Premium Pro desbloquea personalización adicional.

Permisos

Para gestionar correctamente canales, roles y miembros, Klvro necesita los permisos correspondientes y una posición de rol suficiente dentro de la jerarquía de Discord.

Problemas comunes

El bot aparece offline

Comprueba que el servicio donde está alojado Klvro esté activo.

Un comando no aparece

Los comandos globales de Discord pueden tardar un poco en actualizarse después de un cambio.

Klvro no puede gestionar un rol

Mueve el rol del bot por encima del rol que intentas administrar.
